# 儿童成长积分助手 (Kids Growth Points)

一款面向家庭的**游戏化习惯养成工具**，通过积分激励帮助孩子养成好习惯。

## 🎯 产品定位

- **对孩子**: 让好习惯养成变得有趣、有成就感
- **对家长**: 减轻家庭教育负担，可视化孩子的成长进步
- **对家庭**: 建立积极向上的家庭氛围，促进亲子互动

## ✨ 核心功能

| 功能模块 | 说明 |
|---------|------|
| 📋 任务管理 | 日常任务、挑战任务、习惯养成 |
| 🏆 积分系统 | 灵活规则配置、连续打卡奖励 |
| 🛒 奖励商城 | 实物/特权/体验类奖励 |
| 🐾 宠物系统 | 8种宠物、5阶段进化 |
| 🏅 成就系统 | 徽章墙、隐藏成就 |
| 🤖 AI记账 | 自然语言输入、智能识别 |
| 👨‍👩‍👧 家庭管理 | 多孩子、多成员协作 |

## 🛠️ 技术栈

- **前端框架**: uni-app (Vue 3) - 一套代码多端运行
- **UI组件库**: TDesign MiniProgram
- **后端服务**: 微信云开发 (Node.js)
- **数据库**: 云数据库 MongoDB
- **AI服务**: 通义千问/文心一言 API

## 🚀 快速开始

### 环境要求

- Node.js >= 16
- npm >= 8
- 微信开发者工具

### 安装依赖

```bash
npm install
```

### 运行开发

```bash
# 微信小程序
npm run dev:mp-weixin

# H5
npm run dev:h5
```

### 构建发布

```bash
# 微信小程序
npm run build:mp-weixin

# H5
npm run build:h5
```
